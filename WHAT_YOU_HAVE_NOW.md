## 📞 Quick Troubleshooting

### App won't build
```bash
rm -rf node_modules .next
npm install
npm run build
```

### Live site shows blank
```
- Clear browser cache (Ctrl+Shift+Delete)
- Refresh (Ctrl+R)
- Try incognito mode
- Check console (F12)
```

### Video too large (>50 MB)
```
- Export at 1440×810 (not 1920×1080)
- Use H.264 codec, 30 FPS
- Target 5–8 Mbps bitrate
```

### Missing improvement in video
```
- Re-record just that section
- Splice into existing video
- Or redo entire video with all improvements
```
